# Keyboard shortcuts

`Primary` is **⌘** on a Mac and **Ctrl** on Windows and Linux. You can change each one in
**Preferences, Shortcuts**; a chord already used by another command is refused, and **Reset** restores
the built-in ones.

| Command | Shortcut |
|---|---|
| Add downloads | Primary+N |
| Search | Primary+F |
| Command palette | Primary+K |
| Delete the selected downloads | Delete or Backspace |

## Global shortcuts

Two commands work from any program, on macOS, Windows and X11 Linux. They are **off** until you set a
chord in Preferences, need at least one modifier key, and are not offered on Wayland (the system does not
allow them).

| Command | What it does |
|---|---|
| Show or hide DLM | Brings the window forward or hides it |
| Add the link on the clipboard | Opens the add dialog with the first link on the clipboard |

On Linux the global shortcuts need `libkeybinder-3.0` installed.

The command palette (Primary+K) finds every page and action by name, so you rarely need to remember where
something lives.
