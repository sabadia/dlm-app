# DLM user guide

DLM is a download manager for macOS, Windows and Linux. The app shows and controls your
downloads; the downloads themselves are done by the `dlm` service the app starts for you (or one on
another computer that you connect to).

| Page | What it covers |
|---|---|
| [Getting started](getting-started.md) | Install, first start, adding your first download |
| [Downloads](downloads.md) | The list, filters, the details pane, queues, categories |
| [Tools and settings](tools-and-settings.md) | Everything behind the gear button |
| [Browser extension](browser-extension.md) | Pair the extension, expired links |
| [Keyboard shortcuts](shortcuts.md) | Built-in and global shortcuts |
| [Troubleshooting](troubleshooting.md) | When something does not work |

The guide describes the app as it is in the latest release. Parts that need a newer `dlm` service
are marked. Screenshots are in [../images](../images/README.md).
