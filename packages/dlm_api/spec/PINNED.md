`openapi-3.0.json` is the release asset `dlm_0.8.1_openapi-3.0.json` of dlm-server v0.8.1 (v0.7.5's contract plus
the archive: `archived` on tasks, the `archived` list and selector filter and the archived count of the queue list;
`refreshTaskId` on capture; `q`, `engine`, `label` and `category` in the selector filter; the `browser.not_a_page`
problem). To update, replace it with the asset of a newer release and run `tool/generate.sh`.
